### Vrinda Store Annual Report 2022

### Interactive Excel Dashboard Project

## 1. Project Overview

The Vrinda Store Annual Report 2022 is an interactive sales and order analysis dashboard created using Microsoft Excel. It summarizes store performance and helps users explore sales trends, customer demographics, order statuses, and sales channels in one place.

## 2. Excel Skills Demonstrated

- PivotTables: Summarize sales and order data by month, state, channel, gender, age group, and order status.
- Slicers: Filter dashboard results interactively by month, order status, and sales channel.
- Charts and Data Visualization: Create and format combination charts, pie charts, and bar charts.
- Combo Charts and Secondary Axis: Compare total sales and number of orders in a single chart.
- Sorting and Top 10 Analysis: Rank states based on sales performance.
- Data Labels and Percentages: Display values and category percentages directly on charts.
- Dashboard Design and Formatting: Arrange charts and slicers into a clear, easy-to-read dashboard.
- Data Summarization: Convert raw order data into meaningful summaries for business analysis.

## 3. Dashboard Components

| Dashboard View           | Purpose                                                                             |
| ------------------------ | ----------------------------------------------------------------------------------- |
| Monthly Sales and Orders | Compare monthly sales with the number of orders.                                    |
| Sales by Gender          | Show the sales split between men and women.                                         |
| Order Status             | Display delivered, cancelled, refunded, and returned orders.                        |
| Top 10 States            | Identify the states with the highest sales.                                         |
| Age Group and Gender     | Compare order patterns by age group and gender.                                     |
| Sales Channels           | Show the contribution of Amazon, Myntra, Flipkart, Meesho, Ajio, Nalli, and Others. |

## 4. Tools and Features Used

- Microsoft Excel
- PivotTables
- PivotCharts and Excel charts
- Slicers and interactive filters
- Combo charts and secondary-axis configuration
- Chart labels, percentages, and formatting
- Sorting and category-based summaries

## 5. Skills Practiced

Through this project, I practiced organizing sales data, summarizing information with PivotTables, comparing categories, identifying monthly trends, ranking states by sales, and designing an interactive dashboard to make business data easier to understand.

## 6. Project Purpose

The purpose of this project is to demonstrate practical Excel skills for data analysis and dashboard reporting. It highlights how Excel features can be used to present sales and order information in a structured, visual format.
